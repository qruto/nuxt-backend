Use `nuxt-backend/convex/test` to register the packaged `backend` component when testing your Convex functions with [`convex-test`](https://docs.convex.dev/testing/convex-test).

```ts
import { convexTest } from 'convex-test'
import backendTest from 'nuxt-backend/convex/test'
import schema from './schema'

const t = convexTest(schema, modules)
backendTest.register(t)
```

`register(t)` mounts the all-in-one `backend` component into the test harness — `t.registerComponent('backend', …)` — so functions that read auth tables, send email, or call `components.backend.adapter.*` / `components.backend.email.*` / `components.backend.billing.*` / `components.backend.gifts.*` resolve correctly under test.

```ts
function register(
  t: TestConvex<SchemaDefinition>,
): void
// default export: { register, modules: { backend } }
```

::note
`convex-test` does not model nested components, so the email provider child inside `backend` (`backend/resend`) is not exercised under test.
::
