The agent plugin installs, in one step, what a coding agent needs for `nuxt-backend` apps: the skills, the developer MCP server and the docs MCP. Install it once in Claude Code, and every project on the package gets the same help without wiring each piece. A project's own [agent files](/docs/develop/agents/agent-files) still win where they differ, since they match the version that project installed.

## What it bundles

| Part | What it gives the agent | On its own |
|---|---|---|
| The skills | The core skill and a task skill per part of the app | [Agent skills](/docs/develop/agents/skills) |
| The developer MCP server | Project state, the docs, and the Convex, Polar, Resend and Vercel consoles, run in each project | [Developer MCP server](/docs/develop/agents/developer-mcp) |
| The docs MCP | Search, every page, and lookups of findings, env names, composables and components | [Docs MCP](/docs/develop/agents/docs-mcp) |

## Install it

The plugin is published from the package's repository, which is also its marketplace. In Claude Code:

```text
/plugin marketplace add qruto/nuxt-backend
/plugin install nuxt-backend@nuxt-backend
```

`/plugin` lists it afterwards, with its skills and its two servers, `nuxt-backend` and `nuxt-backend-docs`. Its skills are the repository's own, so they follow the newest release. Update it with `/plugin marketplace update nuxt-backend`.

## Other agents

Codex, Cursor, Copilot and the rest take the same pieces one by one:

- **The skills:** `npx skills add https://nuxt-backend.dev --skill '*'` ([Install the skills on their own](/docs/develop/agents/skills#install-the-skills-on-their-own)).
- **The developer MCP server:** `npx nuxt-backend init --agents` writes it into the project's `.mcp.json`, and [Connect it](/docs/develop/agents/developer-mcp#connect-it) shows each client's file.
- **The docs MCP:** one URL, `https://mcp.nuxt-backend.dev/mcp` ([Docs MCP](/docs/develop/agents/docs-mcp)).

## The plugin and the project's agent files

- **The project's skills win.** The plugin brings the newest skills to every project. A project's own copy, in `node_modules/nuxt-backend/skills/` and `.agents/skills/`, describes exactly the version it installed, and its `AGENTS.md` section points the agent there first.
- **One developer server per project.** The plugin's server runs `npx nuxt-backend mcp` inside the open project, on that project's deployment. A project whose `.mcp.json` names it too lists it twice: turn one off in `/mcp`.
- **The ship and upgrade skills** cover the server's command, so an agent learns it where it learns the rest of the CLI.
