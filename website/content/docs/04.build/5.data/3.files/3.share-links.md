A Panels author sends a finished strip to a friend who has no account. The author turns a link on, and anyone holding it can read that one strip on a public page, with a preview card when the link is pasted into a chat. Convex has no sharing of its own. The package adds share links whose token is stored only as a hash, rotation and revocation, a preview card from the row's image, and the share loop: a "made with" badge that carries the sharer's referral code.

## Mark the table shareable

`storage.shareable(table, options)` says who may share a row of the table, where its public page lives and which image its preview card shows:

```ts [backend/storage.ts]
import { setupStorage } from 'nuxt-backend/storage'
import { components } from './_generated/api'
import type { DataModel } from './_generated/dataModel'

// DataModel types the row each table's callbacks receive.
export const storage = setupStorage<DataModel>(components, { stripMetadata: true })

storage.shareable('strips', {
  path: '/s',
  canShare: (ctx, strip) => strip.authorId === ctx.user.id && strip.status === 'ready',
  ogImage: strip => strip.coverId,
})

export const { generateUploadUrl, getFileUrl, getShareLink, enableShareLink, revokeShareLink } = storage.api
```

| Option | Effect |
|---|---|
| `path` | Where the public page lives: a link reads `SITE_URL` + `path` + `/` + the token |
| `canShare` | Whether the signed-in caller may turn the row's link on or rotate it. It receives the row |
| `ogImage` | The storage id of the image the preview card shows, or `null` for none. It receives the row |

`getShareLink`, `enableShareLink` and `revokeShareLink` take `{ table, id }` and answer signed-in accounts only. Turning a link on asks `canShare`. Revoking asks `canShare`, or that the caller turned the link on, so a strip that changed since can still be taken offline.

## Turn a link on from a page

`useShareLink(table, id)` reads whether the row is shared and turns its link on and off:

```vue [app/components/ShareStrip.vue]
<script setup lang="ts">
const props = defineProps<{ stripId: string }>()
const { shared, sharedAt, url, enable, revoke, isPending, error } = useShareLink('strips', () => props.stripId)
</script>

<template>
  <section aria-labelledby="share-heading">
    <h2 id="share-heading">Share this strip</h2>
    <p v-if="url">Anyone with this link can read the strip: <code>{{ url }}</code></p>
    <p v-else-if="shared">Shared since {{ new Date(sharedAt!).toLocaleDateString() }}.</p>
    <button type="button" :aria-disabled="isPending || undefined" @click="isPending || enable()">
      {{ shared ? 'Make a new link' : 'Turn on a link' }}
    </button>
    <button v-if="shared" type="button" :aria-disabled="isPending || undefined" @click="isPending || revoke()">
      Turn the link off
    </button>
    <p v-if="error" role="alert">{{ error.message }}</p>
  </section>
</template>
```

| It returns | |
|---|---|
| `shared`, `sharedAt` | Whether the row has a live link, and since when: live, in every open tab |
| `url` | The link, right after `enable()` in this tab, then `null` after a reload. The token is shown once |
| `enable()` | Mints a link, replacing any earlier one, and resolves with `{ token, url }` |
| `revoke()` | Turns the link off. A page that holds it reads `null` from then on |
| `isPending`, `error` | An action on its way, and why the last one failed, as `{ code, data, message }` |

## Read the shared row on a public page

A public query turns the token back into the row with `storage.resolveShareLink(ctx, table, token)`. It returns `{ id, sharedBy, ogImageUrl }`, or `null` for an unknown or revoked token. Return only what a stranger may see:

```ts [backend/strips.ts]
import { v } from 'convex/values'
import { query } from './_generated/server'
import { referrals } from './referrals'
import { storage } from './storage'

export const shared = query({
  args: { token: v.string() },
  handler: async (ctx, { token }) => {
    const link = await storage.resolveShareLink(ctx, 'strips', token)
    const strip = link ? await ctx.db.get('strips', link.id) : null
    if (!link || !strip || strip.status !== 'ready') return null
    return {
      title: strip.title,
      coverUrl: strip.coverId ? await storage.fileUrl(ctx, strip.coverId) : null,
      ogImageUrl: link.ogImageUrl,
      referralCode: await referrals.codeFor(ctx, link.sharedBy),
    }
  },
})
```

```vue [app/pages/s/[token].vue]
<script setup lang="ts">
import { api } from '#backend/api'

const route = useRoute()
const { data: strip } = await useAsyncQuery(api.strips.shared, { token: route.params.token as string })

useSeoMeta({
  robots: 'noindex',
  referrer: 'no-referrer',
  ogTitle: () => strip.value?.title ?? 'A strip made with Panels',
  ogImage: () => strip.value?.ogImageUrl ?? undefined,
  twitterCard: 'summary_large_image',
})
</script>

<template>
  <main>
    <article v-if="strip">
      <h1>{{ strip.title }}</h1>
      <NuxtImg v-if="strip.coverUrl" provider="backend" :src="strip.coverUrl" alt="" width="960" />
      <a
        :href="strip.referralCode ? `/r/${strip.referralCode}` : '/'"
        :title="strip.referralCode ? 'Made with Panels. The author earns credits when you join.' : undefined"
      >
        Made with Panels: make your own
      </a>
    </article>
    <p v-else>This link no longer works. Ask the author for a new one.</p>
  </main>
</template>
```

The page renders on the server for a visitor with no session, so a chat app's crawler reads the card. Keep `noindex` unless the shared rows are meant for search engines: a link is unlisted, not secret, once someone posts it. `no-referrer` keeps the token out of the requests the page makes to other sites.

## Give the link a preview card

`ogImageUrl` is an [expiring private URL](/docs/build/data/files/images#serve-a-private-file-for-a-while) for the `ogImage` file, valid for seven days and minted again on each read. A crawler can fetch it without a session; it is served by the route `registerBackendRoutes(http, { storage })` mounts ([Show images](/docs/build/data/files/images#serve-a-private-file-for-a-while)). Use a 1200 × 630 image for a large card; the provider can crop one from the cover.

## Close the share loop

The badge links to `/r/<code>`, the sharer's [referral link](/docs/build/growth/offers/referrals), so a reader who signs up is credited to the author. `referrals.codeFor(ctx, userId)` returns the person's code, or `null` when they have none yet or turned it off for their share pages. A mutation or an action makes the code on its first call; a query reads the one that exists, as the page's query above does, so call it from the mutation that turns the link on:

```ts [backend/strips.ts]
export const publish = mutation({
  args: { id: v.id('strips') },
  handler: async (ctx, { id }) => {
    // …check the strip is the caller's and ready, then:
    await referrals.codeFor(ctx, (await ctx.auth.getUserIdentity())!.subject)
  },
})
```

The referral program decides the rewards and caps; the share page only carries the code. Say on the page that the link is a referral, as the program's disclosure asks: the badge's `title` above does.

## What is stored

| Stored | Not stored |
|---|---|
| The table, the row's id, the SHA-256 of the token, when it was turned on and by whom | The token, and the link built from it |

A row's link is deleted with its owner's account erasure. When your code deletes a row, call `storage.revokeShareLink(ctx, table, id)` in the same mutation.

## What happens when…

| Situation | Result |
|---|---|
| The table is not marked shareable | [`invalid_input`](/docs/reference/backend/errors#invalid_input) on `table` |
| `canShare` says no | [`forbidden`](/docs/reference/backend/errors#forbidden), reason `cannot_share` |
| A signed-out caller turns a link on | [`unauthenticated`](/docs/reference/backend/errors#unauthenticated) |
| The token is unknown, rotated or revoked | `resolveShareLink` returns `null` |

## Limits

- **Revoking stops the page, not the files.** A plain file URL works until the file is deleted, and a visitor who opened the page has it. When that matters, store a new file and `release` the old one.
- **One link per row.** Turning a link on again rotates it.
- **No view counts or expiry dates.** Count views with a [counter](/docs/build/data/read-write/aggregates#counts-with-many-writers), and expire links with a [retention rule](/docs/build/data/retention).

## Test it

```ts [backend/strips.test.ts]
import { asUser, defineBackendTestApp } from 'nuxt-backend/test'
import { expect, test } from 'vitest'
import { api } from './_generated/api'
import schema from './schema'

const testApp = defineBackendTestApp(schema, import.meta.glob('./**/*.ts'))

test('a revoked link stops working', async () => {
  const t = testApp()
  const author = await asUser(t)
  const id = await author.mutation(api.strips.create, { title: 'Monday' })
  await author.mutation(api.strips.publish, { id })
  const { token } = await author.mutation(api.storage.enableShareLink, { table: 'strips', id })
  expect(await t.query(api.strips.shared, { token })).toMatchObject({ title: 'Monday' })
  await author.mutation(api.storage.revokeShareLink, { table: 'strips', id })
  expect(await t.query(api.strips.shared, { token })).toBeNull()
})
```
