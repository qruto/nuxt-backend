The module adds `tokens.css` first, then the stylesheet of each component and part of the capabilities it detects. The tokens sit on `:root` and every rule in the `nuxt-backend` cascade layer, which `tokens.css` declares last in `@layer theme, base, reset, nuxt-backend;`. Any CSS of yours outside a layer wins over it without a specificity fight, and `css: false` loads none of it. An app component that replaces a part by name also drops that part's stylesheet. [Restyle with tokens](/docs/build/ui/customize/tokens) shows how to override them; this page lists them, generated from the stylesheets.

## Shared tokens

One override of a `--bk-*` token re-themes every component. A colour is a `light-dark()` pair that follows the app's `color-scheme`; the derived tokens mix from `currentColor`.
