Two ways to consume the surface:

- **Explicit imports** — `import { … } from 'nuxt-backend/…'`, declared in the package `exports` map. The `nuxt-backend/convex*` subpaths run in your **Convex backend** (`backend/`), not the Vue app.
- **Auto-imports** — registered by the module, no `import` needed. Vue composables/components in app code; server utilities in `server/` (Nitro).

## Import tree

```text
nuxt-backend
├─ "nuxt-backend" ............................ Nuxt module (default) + type ModuleOptions
├─ "nuxt-backend/convex/app" ............... defineBackendApp · installBackend · backendEnv
├─ "nuxt-backend/convex" .................... setupAuth · createAuth · createAuthOptions
│                                             makeAuthApi · createBetterAuth · createBetterAuthOptions
│                                             + types CreateBetterAuthOptions · SetupAuthOptions
├─ "nuxt-backend/convex/{billing,email,rate-limit,migrations,aggregate,search,workflows}" .. per-component setup helpers
├─ "nuxt-backend/convex/http" .............. registerBackendRoutes — auth + webhook routes in one call
├─ "nuxt-backend/convex/functions" ......... createFunctions — pre-authorized function builders
├─ "nuxt-backend/convex/authorization" ..... setupAuthorization — roles & permissions
├─ "nuxt-backend/convex/components/backend/convex.config" ... default: the all-in-one `backend` component
├─ "nuxt-backend/convex/components/backend/schema" .. tables · billingTables · authSchema
│                                             vEntitlementBenefit · vEntitlementMeter · vGift · default
├─ "nuxt-backend/convex/components/backend/{email,billing,gifts}" .. the component's function modules
├─ "nuxt-backend/convex/components/backend/_generated/component" .. type ComponentApi  (types only)
├─ "nuxt-backend/convex/auth.config" ....... defineBackendAuthConfig · default · type DefineBackendAuthConfigOptions
└─ "nuxt-backend/convex/test" .............. register · default ({ register, modules })

auto-imports (no import statement)
├─ Vue composables ......... useConvex · useQuery (+ useConvexQuery, useQuery_experimental)
│                            useQueries (+ useConvexQueries) · useMutation (+ useConvexMutation)
│                            useAction (+ useConvexAction) · usePaginatedQuery (+ usePaginatedQuery_experimental)
│                            usePreloadedQuery · usePreloadedAuthQuery · useConvexConnectionState
│                            useUpload · useUploadQueue · useStorageUrl (+ uploadFile)
│                            useConvexAuth · provideConvexAuth · useAuth · useOrganization
│                            useSearch · useAggregate (+ useCount) · useBilling · useFeatures
│                            useCredits · useGifts · useEmailStatus · useWorkflowStatus
├─ Vue components .......... <Authenticated> · <Unauthenticated> · <AuthLoading>
│                            <RoleBoundary> · <FeatureBoundary> · <AcceptInvitation> · <GiftClaimBanner>
├─ Injection ............... useNuxtApp().$convex : ConvexVueClient
└─ Server utils (Nitro) .... fetchQuery · fetchMutation · fetchAction
                             preloadQuery · preloadedQueryResult · backendAuth

aliases ...................... #backend · #backend/api · #backend/server
                             #backend/dataModel · #backend/_generated  (Vite + Nitro)
```

## Exports map

| Export | Use for |
|---|---|
| `nuxt-backend` | The Nuxt module used in `modules: ['nuxt-backend']` |
| `nuxt-backend/convex/app` | `defineBackendApp` / `installBackend` / `backendEnv` — the one-call `convex.config.ts` |
| `nuxt-backend/convex` | App-side helper bridge (`setupAuth`, `createAuth`, `makeAuthApi`, …) |
| `nuxt-backend/convex/http` | `registerBackendRoutes(http, options)` — auth + [webhook routes](/backend-components/webhooks) in one call |
| `nuxt-backend/convex/functions` | `createFunctions(...)` — pre-authorized `authed` / `org` / `admin` / `withRole` builders |
| `nuxt-backend/convex/authorization` | `setupAuthorization(...)` — roles & permissions over the admin plugin |
| `nuxt-backend/convex/components/backend/convex.config` | Mounting the packaged all-in-one `backend` component |
| `nuxt-backend/convex/components/backend/schema` | Base auth + billing/gift tables and validators for local hybrid schema scaffolding |
| `nuxt-backend/convex/components/backend/{email,billing,gifts}` | The component's function modules, re-exported by local installs |
| `nuxt-backend/convex/auth.config` | Creating `auth.config.ts` with `defineBackendAuthConfig(...)` |
| `nuxt-backend/convex/test` | Registering the packaged `backend` component in `convex-test` |
| `nuxt-backend/convex/billing` | `setupBilling(...)` — subscriptions, discounts, prepaid credits & gifts |
| `nuxt-backend/convex/email` | `setupEmail(...)` — transactional email over the `backend` component |
| `nuxt-backend/convex/rate-limit` | `setupRateLimiter(...)` + `DEFAULT_AUTH_LIMITS` |
| `nuxt-backend/convex/migrations` | `setupMigrations(...)` — online schema migrations |
| `nuxt-backend/convex/aggregate` | `TableAggregate`, `withTriggers`, `Triggers` — denormalized counts/sums |
| `nuxt-backend/convex/workflows` | `setupWorkflows(...)` — durable multi-step functions |
| `nuxt-backend/convex/search` | `search(...)` (fluent) + `defineSearch(...)` over native full-text search |

## Selected entrypoint signatures

### `nuxt-backend/convex/auth.config`

```ts
import defineBackendAuthConfig, {
  type DefineBackendAuthConfigOptions,
} from 'nuxt-backend/convex/auth.config'

function defineBackendAuthConfig(options?: DefineBackendAuthConfigOptions): AuthConfig
interface DefineBackendAuthConfigOptions {
  basePath?: string  // default '/api/auth'
  jwks?: string
}
```

### `nuxt-backend/convex/components/backend/schema`

```ts
import {
  tables, billingTables, authSchema,
  vEntitlementBenefit, vEntitlementMeter, vGift,
} from 'nuxt-backend/convex/components/backend/schema'
// tables:        the Better Auth tables (user, session, account, …)
// billingTables: the entitlement cache + billingGifts tables
// default:       the component's full schema (auth + billing/gift tables)
```

### `nuxt-backend/convex` — option types

```ts
interface CreateBetterAuthOptions {
  authConfig?: AuthConfig          // override the default Convex auth config
  authOptions?: BetterAuthOptions  // merged with package defaults
  basePath?: string                // default '/api/auth'
  admin?: AdminPluginOptions | false           // roles/ban/impersonation — on by default
  organization?: OrganizationPluginOptions | false
  // workspaces — on by default, plus `personal` (auto personal workspace)
  // and `invitationPath` (default '/accept-invitation')
}
interface SetupAuthOptions<DM, Schema> extends CreateBetterAuthOptions {
  schema?: Schema                  // local Better Auth schema for hybrid/local installs
  verbose?: boolean                // verbose component client logs
  integrations?: AuthIntegrations  // { email?, rateLimiter?, onUserCreated?, emailTemplates? }
}
```
