The rest of this section is about agents that use your app. This page is about the coding agents that build it, such as Claude Code, Codex, Cursor or Copilot. Three pieces tell them how a `nuxt-backend` app works.

## The agent skill

The `nuxt-backend` skill holds the rules of an app built on the package:

- the neutral names;
- the scaffold contract and `backend/_generated`;
- the CLI and the env contract;
- where each feature lives, and the customization steps in order.

Install it with the [skills CLI](https://skills.sh), from this site or from the repository:

```bash
npx skills add https://nuxt-backend.dev -s nuxt-backend
npx skills add qruto/nuxt-backend -s nuxt-backend
```

Keep `-s nuxt-backend`. The repository also carries the skills its own contributors use, and a bare `add` would offer all of them. The skill carries an install guide too, `references/install.md`: the [agent install prompt](/getting-started/installation#with-an-ai-agent) installs the skill and points the agent at it. The site serves the skill at [`/.well-known/skills/nuxt-backend/SKILL.md`](/.well-known/skills/nuxt-backend/SKILL.md), and [`/llms.txt`](/llms.txt) links it beside the docs.

## What `init` writes

`npx nuxt-backend init` writes two files for agents next to the scaffold. The [starter template](/getting-started/templates) ships them too.

- **`AGENTS.md`**: a short `nuxt-backend` section between `<!-- nuxt-backend-start -->` and `<!-- nuxt-backend-end -->` markers. It covers the rules, the commands, the env and where the docs are.
  - A missing file is created.
  - An existing one without the markers gets the section appended, and nothing else changes.
  - Once the markers exist, `init` leaves the file alone. `init --force` replaces only what sits between them.
- **`.mcp.json`**: the Convex MCP server, `npx convex mcp start`, which reads your deployment's tables, functions, logs and env.
  - A missing file is created.
  - An existing one gains a `convex` server only when it has none, keeping its indentation.
  - A file that is not valid JSON is left alone with a warning.

Claude Code reads `CLAUDE.md` and follows `AGENTS.md` only when `CLAUDE.md` imports it. When your `CLAUDE.md` does not mention `AGENTS.md`, `init` says to add an `@AGENTS.md` line. It never edits that file.

`init --no-agents` writes neither file.

## Convex's own tooling

Inside `backend/`, the rules are Convex's:

- `npx convex ai-files install` writes Convex's guidelines for agents.
- The MCP server in `.mcp.json` lets an agent query the deployment instead of guessing.
