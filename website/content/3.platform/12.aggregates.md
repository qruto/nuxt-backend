Construct one `TableAggregate` per mounted instance and keep it in sync automatically with triggers.

```ts [backend/aggregates.ts]
import { TableAggregate, Triggers, withTriggers } from 'nuxt-backend/aggregate'
import { components } from './_generated/api'
import { mutation as rawMutation, query } from './_generated/server'
import type { DataModel } from './_generated/dataModel'

export const messagesCount = new TableAggregate<{
  Key: null
  DataModel: DataModel
  TableName: 'messages'
}>(components.aggregate, { sortKey: () => null })

const triggers = new Triggers<DataModel>()
triggers.register('messages', messagesCount.trigger())

// Use this wrapped `mutation` instead of the raw one so writes keep the aggregate in sync.
export const mutation = withTriggers(rawMutation, triggers)

// The query `useCount` reads.
export const countMessages = query({
  args: {},
  handler: ctx => messagesCount.count(ctx),
})
```

That query is the server half; read it reactively on the client:

```vue
<script setup lang="ts">
import { api } from '#backend/api'

// Live aggregate count (coerces loading/null to 0). `useCount` is an alias.
const messageCount = useCount(api.aggregates.countMessages)
</script>
```

::note
`useAggregate` and `useCount` are the same composable; `useCount` reads better when you're counting rows.
::

## Sums and more instances

A sum is the same aggregate with a `sumValue` — `new TableAggregate<…>(components.aggregate, { sortKey: () => null, sumValue: message => message.text.length })` — read with `.sum(ctx)` in the query and `useAggregate` on the client.

Each aggregate needs its own component instance. The scaffold mounts one (`app.use(aggregate)` → `components.aggregate`); for a second table, sort key, or sum, mount the component again under a name in `convex.config.ts` — `app.use(aggregate, { name: 'messagesSize' })` — and pass `components.messagesSize` to that `TableAggregate`.

Triggers only see writes made after they are registered. Backfill a table that already has rows once with a [migration](/platform/migrations) whose `migrateOne` calls `messagesCount.insertIfDoesNotExist(ctx, doc)` — idempotent, so it is safe to re-run.
