Zero-config mode mounts the packaged components and registers Better Auth HTTP routes from `backend/http.ts`. The default route is `/api/auth`.

## Extend Better Auth options

To keep the packaged component but extend Better Auth options such as providers or plugins, pass `authOptions` to `setupAuth(...)`:

```ts [backend/auth.ts]
import { setupAuth } from 'nuxt-backend/auth'
import { components } from './_generated/api'
import { query } from './_generated/server'

export const {
  authComponent,
  createAuthOptions,
  options,
  createAuth,
  getAuthUser,
} = setupAuth(components, query, {
  authOptions: {
    appName: 'Acme',
    emailAndPassword: {
      enabled: true,
    },
  },
})
```

::note
`emailAndPassword` is off by default — the package is passwordless (passkey + OTP): the shipped `<AuthForm>` and `useLoginFlow()` offer only those two, and the [default rate limits](/platform/rate-limiting) carry no password limits. Enabling it, as above, is supported — but the sign-in form is yours to build, and none of the package's named limits covers the password routes: Better Auth's own per-path limiter still fronts them, so add named limits of your own if you want per-identity throttling there.
::

## Change the auth route

If you want a different auth route, update all three places so they match — the Nuxt module's `backend.authRoute`, Better Auth `basePath`, and the Convex auth config.

`backend/convex.config.ts` stays exactly as [scaffolded](/platform/auth/setup#the-scaffolded-files) — the auth route is not part of the app definition.

```ts [backend/auth.ts]
export const {
  authComponent,
  createAuthOptions,
  options,
  createAuth,
  getAuthUser,
} = setupAuth(components, query, {
  basePath: '/internal/auth',
})
```

```ts [backend/auth.config.ts]
import { defineBackendAuthConfig } from 'nuxt-backend/auth.config'

export default defineBackendAuthConfig({
  basePath: '/internal/auth',
})
```

::warning
If you change the Nuxt module's `backend.authRoute`, keep these Convex component helpers on the same path. The Nuxt proxy route, Better Auth `basePath`, and `defineBackendAuthConfig({ basePath })` must all match.
::

::tip{to="/tooling/local-installation"}
Need full Better Auth ownership beyond route wiring — custom schema, indexes, or plugins that change the schema? Switch the first scaffold to local hybrid installation.
::
