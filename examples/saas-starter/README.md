# SaaS starter

A minimal, realistic product built on [`nuxt-backend`](../../README.md) —
passwordless auth, multi-workspace tenancy, roles, and workspace-owned billing,
composed the way a real app would.

## What it demonstrates

| Piece | Where |
|---|---|
| Passwordless sign-in (`<AuthForm>`, passkeys + OTP) | `app/pages/login.vue` |
| Workspaces: personal on sign-up, create/switch/invite (`useOrganization`, `<OrganizationBoundary>`) | `app/pages/app/index.vue` |
| Workspace-scoped live data (`org.query` / `org.mutation` builders) | `convex/projects.ts` |
| Workspace-owned billing + feature gates + credits (`useBilling`, `<CheckoutLink>`) | `app/pages/app/billing.vue` |
| App-wide roles (`<RoleBoundary>`, `setUserRole` bootstrap) | `app/pages/app/admin.vue` |
| Scaffolded backend (generated by `npx nuxt-backend init`) | `convex/` |

## Run it

```bash
pnpm install                       # from the repo root
cd examples/saas-starter
cp .env.example .env.local         # fill in after `convex dev` prints the URLs

npx convex dev                     # terminal 1 — provisions a dev deployment + codegen
pnpm dev                           # terminal 2
```

Then:

```bash
npx convex env set BETTER_AUTH_SECRET "$(openssl rand -base64 32)"
npx convex env set SITE_URL http://localhost:3000
# optional integrations (each no-ops until set):
npx convex env set RESEND_API_KEY re_...           # email — use test mode + delivered@resend.dev
npx convex env set POLAR_ORGANIZATION_TOKEN ...    # billing — use the Polar sandbox
npx convex env set POLAR_SERVER sandbox
```

Sign in at `/login` (with Resend unconfigured, the OTP code is printed in the
`convex dev` logs). A personal workspace is created automatically; create a
second one and switch — the project list, plan, and credits all follow the
active workspace.

## Decisions worth copying

- **Tenancy rides on identity claims.** `org.*` functions read the active
  workspace from the JWT — no tenant argument threading, and switching
  workspaces re-authenticates the live connection so every query re-scopes.
- **The backend component owns SaaS state.** Auth tables, the entitlement
  cache, and email delivery state live inside the bundled component —
  `convex/schema.ts` contains only *your* tables.
- **Billing is workspace-owned by default** (`billTo: 'organization'`): members
  share the workspace's subscription and credits. Switch to `billTo: 'user'`
  in `convex/billing.ts` for B2C.
